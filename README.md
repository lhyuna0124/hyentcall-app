# ENT 응급콜 관리 (entcall-app)

이비인후과 전공의 응급실 백콜 노티 작성 + 입원 통계 + 전공의 역량 평가를 위한 Next.js 앱입니다.

## 1. 로컬에서 실행

```bash
npm install
npm run dev
```

`http://localhost:3000` 접속. KV 환경변수가 없으면 메모리 저장소로 자동 동작합니다 (서버 재시작 시 데이터 초기화).

## 2. Vercel 배포

1. 이 폴더를 GitHub 저장소에 올린 뒤 Vercel에서 Import.
2. **Storage → Create Database → KV** 로 KV(Redis)를 생성해 프로젝트에 연결하세요.
   연결하면 `KV_REST_API_URL`, `KV_REST_API_TOKEN` 환경변수가 자동으로 추가되고,
   이때부터 노티 기록/평가/알고리즘 설정이 영구 저장됩니다. (KV 연결 전에는 서버 재배포마다 데이터가 초기화됩니다.)
3. Deploy.

## 3. 계정 설정 (중요)

`lib/residents.ts` 에서 이름/연차/로그인용 휴대폰 뒷 4자리를 실제 값으로 반드시 교체하세요.
현재는 예시로 `0000` 이 들어가 있습니다. 관리자 계정(`isAdmin: true`)도 같은 파일에서 설정합니다.

> 이 로그인 방식은 이름 + 전화번호 뒷 4자리만 확인하는 **간단한 인증**입니다.
> 환자 개인정보(등록번호 등)는 저장하지 않도록 설계했지만, 노티 기록에 환자 이름/나이/진단명이 남습니다.
> 병원 내부망 전용으로만 접근 가능하게 하거나(사내 VPN, IP 제한), 최소한 URL을 외부에 공유하지 않는 것을 권장합니다.
> 더 강한 보안이 필요하면 NextAuth + 병원 SSO 연동을 추가로 고려하세요.

## 4. 주요 화면

- `/` 로그인 (이름 + 휴대폰 뒷 4자리)
- `/notify` 응급 노티 작성 — 신체진찰 체크박스, Lab 붙여넣기 자동 인식(▲▼ 표시), Neck CT 소견 입력,
  최종 노티 텍스트 생성 후 "복사하기"로 카카오톡에 바로 붙여넣기 가능. 위험도 배지와 권장 연락 방식이 자동 표시됩니다.
- `/stats` 날짜별/전공의별 입원 건수 통계
- `/admin` (관리자 전용) 전공의별 요약, 역량 평가 입력(질환별 1~5점), 응급질환 위험도 알고리즘 수정

## 5. 위험도 알고리즘 기본값

`lib/triage.ts` 에 정의되어 있고, 관리자 화면(`/admin`)에서 즉시 수정할 수 있습니다.

- **즉시 입원(HIGH) 기본 대상**: Airway trauma, Postop bleeding, Deep neck infection, Acute epiglottitis
- **위험도 자동 상향 규칙**: True vocal cord 미확인 시 HIGH, Epiglottis swelling(+) + Dyspnea 동반 시 HIGH

## 6. Lab 정상범위

`lib/labRules.ts` 에서 병원 검사실 기준으로 low/high 값을 조정하세요. WBC/CRP는 항상 표기되고,
그 외 항목은 이상치일 때만 자동으로 노티 텍스트에 포함됩니다 (▲ 상승 / ▼ 저하).

## 7. 노티(연락) 방식 제안 — 요약

앱에 넣은 기본 규칙(`lib/contactPolicy.ts`)은 아래 원칙을 코드로 옮긴 것입니다. 실제 운영하며 과 정서/병원 상황에 맞게 조정하세요.

- **HIGH (airway trauma, postop bleeding, deep neck, epiglottitis 등)**: 시간대 무관 반드시 전화. 미응답 시 5분 간격 재발신, 2회 실패하면 차상급자(치프/당직 교수)로 에스컬레이션. 카톡은 "왔다갔다 확인" 용도가 아니라 백업 기록용으로만.
- **MEDIUM**: 주간엔 전화가 기본. 새벽엔 정리된 노티장을 카톡으로 먼저 보내고 10~15분 내 회신이 없으면 전화로 전환.
- **LOW**: 정리된 노티장을 카톡으로 보내고 30분 내 회신이 없을 때만 전화 1회. 해당 질환에 대해 관리자 평가 점수가 높은(예: 4~5점) 전공의라면, 통상적인 케이스는 노티 후 통상 진행하고 사후 보고만으로도 무방하도록 과 내 규칙을 정하는 걸 추천합니다 — 이러면 신뢰도가 쌓인 질환에 대해서만 선별적으로 "새벽에 전화 안 받아도 우선 진행" 규칙을 적용할 수 있어, 저년차 전공의의 '교수님 노티 마음고생'과 상급자의 '새벽에 계속 깨는 부담'을 함께 줄일 수 있습니다.
- 다만 **airway compromise 가능성이 조금이라도 있는 케이스(TVC 미확인 포함)는 역량 점수와 무관하게 항상 즉시 전화 원칙**을 유지하는 것을 권장합니다.

## 8. 향후 개선 아이디어 (선택)

- 카카오톡 알림톡/비즈메시지 API 연동으로 "복사 후 붙여넣기"를 자동 전송으로 대체
- 관리자용 알고리즘 수정 이력(변경 로그) 저장
- 전공의 본인 화면에서 본인 평가 추이 그래프로 확인
